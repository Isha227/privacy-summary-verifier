# Data availability and local structure

The public repository contains code and final aggregate results. It does not
publish API keys, restricted blinding keys, completed individual researcher
workbooks or third-party policy files whose redistribution has not been
confirmed.

To run the full prototype locally, place the contemporary experiment, OPP-115
experiment and cleaned contemporary source text under this data folder using
the paths documented by the configuration.

The identifiers are preserved because they link summaries, source units,
evaluator decisions and evidence passages. Aggregate non-identifying outputs
are provided under results using descriptive names.
