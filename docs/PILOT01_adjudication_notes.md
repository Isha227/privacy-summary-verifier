# PILOT01 adjudication meeting notes

The alignment sheet contains 25 provisional concepts. It is a comparison aid,
not the final gold standard. All three researchers must approve each retained,
merged, split, or rejected unit.

## Main disagreements to resolve

1. **Granularity:** A2 combines permission and service-improvement purposes in
   one C2 unit; A1/A3 split them. Decide whether each can be scored independently.
2. **Classification vs profiling:** A1 places IP-based language customisation in
   C1; A3 uses C6. Select one category without duplicating the proposition.
3. **Legal-request detail:** A1/A3 separate disclosure, notice, good-faith legal
   belief, and preservation of objections. A2 records fewer units. Decide which
   are independently material for a lay summary.
4. **Material qualifiers:** A2 often gives the same core proposition but omits
   contractual limits, de-identification, legal prohibitions on notice, purpose-
   limited retention, and protective steps after a breach. Preserve these as
   qualifiers rather than automatically creating extra units.
5. **Jurisdiction-specific link:** A1/A3 include the separate-resource notice for
   EU/EEA/Swiss/California users; A2 omits it. Decide whether a pointer to another
   document is important enough for the coverage denominator.
6. **Effective-date statement:** A1/A3 treat posting an effective date as a unit;
   A2 omits it. Decide whether this is substantive policy-administration content.

## Meeting procedure

For each `ADJ-01`–`ADJ-25` row:

1. Read the three original formulations and source evidence.
2. Choose `retain`, `merge`, `split`, or `reject` in `adjudication_decision`.
3. If retained, assign a final ID such as `P01-C1-U01`.
4. Write one neutral final proposition and its material qualifiers.
5. Record a short rationale, especially for non-unanimous decisions.

Do not inspect generated summaries during adjudication. Once all rows are
decided, lock the file and use only retained final units for coverage scoring.
