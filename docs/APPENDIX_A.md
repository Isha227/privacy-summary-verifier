# Appendix A: Source Code and Reproducibility Materials

The source code, frozen prompt templates, experiment configurations,
evaluation procedures, MiniCheck notebooks, prototype application and
supporting documentation are available in the following private GitHub
repository:

https://github.com/Isha227/privacy-summary-verifier

Large experimental datasets, API keys, restricted blinding files and
researcher-identifying materials are excluded from the repository. The
repository README explains the required local data structure, the commands
used to reproduce the experimental pipeline and how to run the Privacy Summary
Verifier prototype.
